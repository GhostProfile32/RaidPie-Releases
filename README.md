# RaidPie
[Download the latest RaidPie.exe](https://github.com/GhostProfile32/RaidPie-Releases/releases/latest/download/RaidPie.exe) · [Release notes](https://github.com/GhostProfile32/RaidPie-Releases/releases/latest)
No GitHub account or token is needed. Download the EXE to a permanent folder and run it on 64-bit Windows.
## Updating
Inside RaidPie, click **Check for updates**. If a newer release is available, accept the download and restart. The app verifies the checksum and executable version; settings and saved plans stay on your PC.
**Coming from v0.3.0 or earlier?** Close RaidPie and replace your old EXE with v0.3.1 or later once. Those older builds use a private update feed. After this one-time replacement, the update button uses this public repository.
This repository contains downloads and instructions only. Application source is maintained separately. GitHub’s automatically generated source archives contain this README, not the application source.
Requires .NET Framework 4.8 and Windows PowerShell 5.1. Game updates may require a new reader profile. RaidPie is an unofficial companion; game artwork belongs to its respective rights holders.
